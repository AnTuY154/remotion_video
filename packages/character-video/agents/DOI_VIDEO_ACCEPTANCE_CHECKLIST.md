- [ ] amber-gold eyes

- [ ] round soft face

## Motion
- [ ] subtle breathing

- [ ] body weight shift

## Yarn interaction
- [ ] paw contact reads clearly

- [ ] yarn has damping / bounce
- [ ] string curve follows the ball

## Technical
- [ ] no alpha artifact
- [ ] no pixel corruption
- [ ] no visible hole in body
- [ ] no broken frame
- [ ] final MP4 opens correctly
